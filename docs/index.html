THE LAST CARETAKER

Unofficial Multiplayer Mod

Bringing co-op survival to the desolate facility. A proof-of-concept mod to show the developers the true potential of multiplayer.

View on GitHub Get UE4SS on Nexus

📸 See it in Action

Player avatars synchronized in real-time across two separate game clients.

✨ Features & Current State

  • 🏃 Real-time Tracking: See the other player moving around in your world.
  • 🚪 Door Synchronization: Open and close doors together. (Ensure you slide them to the very end of their track for proper network sync).
  • 🛡️ Stability Focused: Stripped down to essential features to prevent memory crashes.

⚠️ Limitations & Known Issues

  • 🎒 No Item Sync: Dropping and picking up items is currently disabled to prevent severe engine crashes.
  • 👻 Animation Desync: The avatar currently slides to match coordinates rather than playing full walking animations.
  • 🐛 Experimental: You might encounter occasional bugs, though recent tests have been very stable.

⚙️ Requirements & Installation

Tested Game Version: v.0.8.0.612251 (Early Access)

  1. Download the latest release from the GitHub repository.
  2. Download the specific UE4SS build from the Nexus Mods page.
  3. Extract the ue4ss folder into your game's binary directory:
    \The Last Caretaker (Early Access)\Voyage\Voyage\Binaries\Win64\
  4. Run the Start_Connection.bat script on both computers to bridge the network.
  5. Launch the game and find your friend!
